## Avant de committer — checklist d'anonymisation

- [ ] aucune barre de favoris / onglets visibles (recadre sur le contenu Wazuh)
- [ ] aucune IP publique
- [ ] aucun nom lié à un employeur ou à l'école
- [ ] aucun token / mot de passe / identifiant à l'écran
- [ ] les IP privées `192.168.154.x` sont sans danger, tu peux les laisser

> Tant qu'une image n'est pas déposée, GitHub affiche un cadre « image manquante » à
> son emplacement dans la doc. Dès que tu ajoutes le fichier au bon nom, elle apparaît.
